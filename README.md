# Python新能源汽车数据分析系统

## 核心功能
- 登录注册
- 汽车信息管理
- 汽车配置管理
- 汽车评论管理
- 交流互动管理
- 留言反馈管理
- 公告信息
- 我的收藏
- 新能源汽车数据可视化大屏

## 适用场景
- 新能源汽车行业数据分析
- 政府部门新能源汽车政策研究
- 行业报告编制
- 汽车制造商市场调研
- 汽车销售商市场分析

## 技术特点
- 使用Django框架构建后端
- MySQL数据库存储数据
- Vue框架实现前端界面
- 数据可视化大屏展示新能源汽车数据
- 支持用户和管理员权限管理
